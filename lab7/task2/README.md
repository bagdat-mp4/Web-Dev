# Lab 7 — Task 2: OOP in Python

## Description
A class hierarchy demonstrating OOP concepts in Python.

## Structure
- `models.py` — Base class `Animal` and child classes `Dog`, `Cat`
- `main.py` — Usage demonstration

## OOP Concepts Used
- **Inheritance** — Dog and Cat inherit from Animal
- **Polymorphism** — `speak()` method overridden in each class
- **Encapsulation** — attributes set in `__init__`
- **`__str__`** — string representation for each class

## How to Run
```bash
python main.py
```
